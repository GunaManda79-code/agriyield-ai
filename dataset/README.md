## Features
1. `crop`: Categorical string (e.g., Rice, Wheat, Maize, Cotton, Soybean).
2. `rainfall`: Annual/Seasonal total rainfall in millimeters (numeric).
3. `temperature`: Average temperature in degrees Celsius (numeric).
4. `humidity`: Relative humidity percentage (numeric).
5. `soil_ph`: Soil pH level (numeric, 0-14).
6. `nitrogen`: Soil Nitrogen content (mg/kg).
7. `phosphorus`: Soil Phosphorus content (mg/kg).
8. `potassium`: Soil Potassium content (mg/kg).
9. `yield`: Target variable, crop yield in tonnes per hectare (t/ha).
